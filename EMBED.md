# Embed the Cali Reign vote flow

Use `landing.html` as the entry point when embedding or linking the experience:

```html
<iframe
  src="https://YOUR-DOMAIN/landing.html"
  width="100%"
  height="900"
  style="border:0"
  title="Cali Reign Tour Vote"
></iframe>
```

Or link directly:

```
https://YOUR-DOMAIN/landing.html
```
